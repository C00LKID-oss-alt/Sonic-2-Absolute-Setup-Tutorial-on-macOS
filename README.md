# Sonic-2-Absolute-Setup-Tutorial-on-macOS
This is a better tutorial on how to setup Sonic 2 Absolute on macOS

## Prerequisites
-UTM: https://getutm.app/

-Your legally obtained Data.rsdk of Sonic 2 (2013)

-The macOS port of Sonic 2 Absolute: https://github.com/Sappharad/Sonic-1-2-2013-Decompilation/releases/tag/v1.3.0-foreverNov2023

-The S2A Setup folder: https://teamforeveronline.wixsite.com/home/sonic-2-absolute

## Step 1: Setting up Sonic 2 Absolute
First, you need to extract the setup folder and move the Data.rsdk to the setup folder.

Now, **make sure the setup folder stays in your Downloads folder do not move it anywhere else until I say so.**

## Step 2: Creating a Windows VM
Now, once you did the steps above, open UTM and create a Windows virtual machine.

Choose Virtualize, then after go to the "Windows" section and tick **"Install Windows 10 or higher" and "Install drivers and SPICE tools"** if not ticked.

After, **continue to the "Shared Directory" and select your Downloads folder and untick "Share is read only" if ticked.**

Now i am not going to tell you how to set it up but you can watch this video right to set one up here: https://youtu.be/3W-Dm12UiRQ

## Step 3: Running the setup
Ok, after setting up your Windows VM, log into your Windows account and open File Explorer.

Scroll to "This PC" on the sidebar and select it. 

Then you should see many drives and one called "Network Drive (Z:)" click on it and it should show your Downloads folder from your Mac that you shared to the Windows VM.

Then you should see the S2A setup folder.

Go inside the folder and run "S2A Setup.bat" by clicking on it two times.

The process might take a while but I will assume that you're very patient, somehow...

The results will be the Data, Scripts and Mods folders along with other files appearing in the setup folder.

## Step 4: Setting up the RSDKv4 Engine for Sonic 2 Absolute
This step will be the last step of setting up Sonic 2 Absolute.

Shut down your Windows VM or just simply close it and close UTM.

Now, on your Mac, create a folder somewhere, such as in "/Applications/" so you could put the RSDKv4.app you got from the .dmg file and the Data, Scripts and Mods folders as well.

Then open the .dmg file and move RSDKv4.app to the folder you just created, and also move the Data, Scripts and Mods folders from the setup folder to the same folder as the RSDKv4.app.

Finally click on RSDKv4.app and you could finally play Sonic 2 Absolute v1.2.1 on macOS!

### You thought that was the end? Because now that you finished setting up S2A on your Mac, let's install some mods in the game!

## Step 5: Installing Mods!
To install mods you need to download some mods, here, this is where you can download mods: https://gamebanana.com/games/15019 

Once you downloaded the mods you like, extract them and put them in the Mods folder where your RSDKv4.app is located in.

Then, enable your mod or mods in-game and you could finally play S2A with mods on macOS!

Later, you can customise the app icon and rename it to make it look better!
